# Bruinet.Maui.Headless

MauiHeadless implementation for Bruinet.Maui: the same page objects and controls on a page rendered headless, without a device, emulator or window (docs/guides/maui-headless.md).

```bash
dotnet add package Bruinet.Maui.Headless
```

**Name with it:** Bruinet.Maui; it brings MauiHeadless.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
