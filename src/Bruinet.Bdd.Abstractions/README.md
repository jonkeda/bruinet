# Bruinet.Bdd.Abstractions

The step attributes of Bruinet's Markdown feature files (BddGiven, BddWhen, BddThen, BddState, BddNamespace), for page-object and control projects that declare phrases without running them.

```bash
dotnet add package Bruinet.Bdd.Abstractions
```

**Name with it:** Only the attributes: a page-object project that declares phrases. A suite names Bruinet.Uat.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
