# Bruinet.Maui.CommunityToolkit

CommunityToolkit.Maui controls for Bruinet UI testing framework.

```bash
dotnet add package Bruinet.Maui.CommunityToolkit
```

**Name with it:** Bruinet.Maui, for an app on CommunityToolkit.Maui.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
