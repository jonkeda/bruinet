# Bruinet.Traits

Typed xUnit trait attributes for the test tier, owner, journey and run set, and a check that every test in an assembly carries one tier and one owner.

```bash
dotnet add package Bruinet.Traits
```

**Name with it:** Any xUnit test project.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
