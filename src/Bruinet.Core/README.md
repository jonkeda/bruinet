# Bruinet.Core

Platform-agnostic UI testing abstractions for .NET applications. Provides interfaces and base classes for building cross-platform UI test automation.

```bash
dotnet add package Bruinet.Core
```

**Name with it:** Nothing alone: a stack package (Bruinet.Html, Bruinet.Maui, Bruinet.Wpf, ...) brings it.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
