# Bruinet.TestData

Typed, strictly validated test data for Bruinet tests: test-set definitions, rules, diagnostics with file and line, and JSON schema export.

```bash
dotnet add package Bruinet.TestData
```

**Name with it:** A suite that loads typed test sets.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
