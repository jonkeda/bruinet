# Bruinet.Maui

MAUI UI testing automation. Provides controls, page objects, and driver factory for cross-platform MAUI application testing.

```bash
dotnet add package Bruinet.Maui
```

**Name with it:** A head: Bruinet.Maui.FlaUI (Windows), Bruinet.Maui.Appium (Android, iOS), Bruinet.Maui.Headless (no device).

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
