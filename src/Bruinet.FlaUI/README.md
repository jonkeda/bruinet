# Bruinet.FlaUI

What the UI Automation stacks share over FlaUI (MAUI on Windows, WPF, WinForms): the desktop app session (launch, attach, the quiet foreground, window placement, screenshots), how a removed element is reported, the runtime id as an element's identity, one-attempt lookups and locators.

```bash
dotnet add package Bruinet.FlaUI
```

**Name with it:** Brought by Bruinet.Wpf, Bruinet.WinForms and Bruinet.Maui.FlaUI.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
