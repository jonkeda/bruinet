# Bruinet.Mocking.Data.EntityFrameworkCore

The SQL log for EF Core apps: an interceptor that logs every command and connection open without changing what EF reads.

```bash
dotnet add package Bruinet.Mocking.Data.EntityFrameworkCore
```

**Name with it:** Bruinet.Mocking.Data, in an EF Core app.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
