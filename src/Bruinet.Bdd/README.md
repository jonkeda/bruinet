# Bruinet.Bdd

Markdown feature files for Bruinet: parse, bind, values, tables, callable steps, namespaces and run, with no UI.

```bash
dotnet add package Bruinet.Bdd
```

**Name with it:** Bruinet.Uat to run the feature files under xUnit.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
