# Bruinet.Html

HTML/Web UI testing automation abstractions. Provides controls and page objects for general web application testing.

```bash
dotnet add package Bruinet.Html
```

**Name with it:** A head: Bruinet.Html.Playwright for a browser, Bruinet.Html.Bunit for bUnit.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
