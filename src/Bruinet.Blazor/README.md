# Bruinet.Blazor

Blazor UI testing automation using Playwright. Provides controls and page objects for Blazor Server and WebAssembly application testing.

```bash
dotnet add package Bruinet.Blazor
```

**Name with it:** Bruinet.Html and a head.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
