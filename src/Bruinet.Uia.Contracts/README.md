# Bruinet.Uia.Contracts

The wire contract for Bruinet's custom UI Automation pattern: ids, verbs, and the registrar interop shared by the app under test and the test assembly.

```bash
dotnet add package Bruinet.Uia.Contracts
```

**Name with it:** Brought by the FlaUI stacks and the app-side bridge.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
