# Bruinet.Stride.Protocol

The wire between a Stride game and its tests: the automation commands, responses and element states, and the named
pipe that carries them.

```bash
dotnet add package Bruinet.Stride.Protocol
```

**Name with it:** nothing: Bruinet.Stride and Bruinet.Stride.Automation bring it.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
