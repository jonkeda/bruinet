# Bruinet.Wpf

WPF UI testing on the call model (AD-010), through UI Automation's patterns over Bruinet.FlaUI: generated controls with WPF's names, pages, containers and collections, one call per member.

```bash
dotnet add package Bruinet.Wpf
```

**Name with it:** Nothing more: it brings Bruinet.FlaUI.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
