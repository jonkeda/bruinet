# MauiHeadless

Headless component testing for .NET MAUI: pages, views and view models rendered in memory, driven and asserted without a device, emulator or window.

```bash
dotnet add package MauiHeadless
```

**Name with it:** Bruinet.Maui.Headless for page objects, or alone for component tests.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
