# Bruinet.Html.Playwright

Playwright-based implementation for Bruinet.Html. Provides PlaywrightHtmlElement and PlaywrightTestContext for browser automation.

```bash
dotnet add package Bruinet.Html.Playwright
```

**Name with it:** Bruinet.Html; then install Chromium with the playwright.ps1 the build writes.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
