# Bruinet.Maui.Appium

Appium-based driver implementation for MAUI UI testing on iOS and Android platforms.

```bash
dotnet add package Bruinet.Maui.Appium
```

**Name with it:** Bruinet.Maui, and an Appium server with UiAutomator2 or XCUITest.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
