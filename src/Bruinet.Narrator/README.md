# Bruinet.Narrator

Narrated recordings of scenario runs: video scripts (*.video.md), their check against the feature files, and the plan a recording follows.

```bash
dotnet add package Bruinet.Narrator
```

**Name with it:** Bruinet.Recording; Bruinet.Narrator.Windows for the Windows voices.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
