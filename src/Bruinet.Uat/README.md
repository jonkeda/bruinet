# Bruinet.Uat

Markdown-driven UAT parsing and execution core for Bruinet.

```bash
dotnet add package Bruinet.Uat
```

**Name with it:** A stack package for the app (Bruinet.Html, Bruinet.Maui, ...).

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
