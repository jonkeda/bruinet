# Bruinet.Mocking

API mocking infrastructure for UI tests. Provides WireMock-based mock servers for simulating backend services during testing.

```bash
dotnet add package Bruinet.Mocking
```

**Name with it:** A UI suite whose app calls services or reads sensors.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
