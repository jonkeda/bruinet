# Bruinet.NativeAndroid

Page objects, controls and the Appium driver for native Android apps (UiAutomator2), in the shape of Bruinet's MAUI and Html stacks.

```bash
dotnet add package Bruinet.NativeAndroid
```

**Name with it:** An Appium server with UiAutomator2.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
