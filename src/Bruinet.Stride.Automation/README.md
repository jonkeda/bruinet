# Bruinet.Stride.Automation

In-game automation server for Stride applications. Embeds into game to handle UI automation requests from Bruinet.Stride test client.

```bash
dotnet add package Bruinet.Stride.Automation
```

**Name with it:** The game; Bruinet.Stride in the test project.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
