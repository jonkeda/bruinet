# Bruinet.Maui.FlaUI

FlaUI-based driver implementation for MAUI UI testing on Windows platform.

```bash
dotnet add package Bruinet.Maui.FlaUI
```

**Name with it:** Bruinet.Maui, and the app built with Bruinet.Maui.AppSupport's bridge.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
