# Bruinet.NativeIos

Page objects, controls and the Appium driver for native iOS apps (XCUITest), in the shape of Bruinet's MAUI and Html stacks.

```bash
dotnet add package Bruinet.NativeIos
```

**Name with it:** An Appium server with the XCUITest driver.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
