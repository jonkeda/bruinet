# Bruinet.Narrator.Windows

What a narrated recording needs on Windows, both from the Windows 10 SDK: the window recorder (Windows.Graphics.Capture, which records a window while it is covered) and Windows' own voices (Windows.Media.SpeechSynthesis), offline.

```bash
dotnet add package Bruinet.Narrator.Windows
```

**Name with it:** Bruinet.Narrator.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
