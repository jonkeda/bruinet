# Bruinet.Html.Bunit

bUnit implementation for Bruinet.Html: the same page objects and controls on a rendered component, without a browser.

```bash
dotnet add package Bruinet.Html.Bunit
```

**Name with it:** Bruinet.Html, for Blazor components with no browser.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
