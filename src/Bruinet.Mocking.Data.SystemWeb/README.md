# Bruinet.Mocking.Data.SystemWeb

The SQL replay test-id hook for a System.Web app on IIS (WebForms, MVC 5): an IHttpModule.

```bash
dotnet add package Bruinet.Mocking.Data.SystemWeb
```

**Name with it:** Bruinet.Mocking.Data, in an ASP.NET app on the .NET Framework.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
