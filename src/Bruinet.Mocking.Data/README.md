# Bruinet.Mocking.Data

The SQL log: every command a test sends, its time and the objects it touches, from an ADO.NET wrapper, EF Core or SQL Server's Extended Events; the schema snapshot. No values and no rows are recorded.

```bash
dotnet add package Bruinet.Mocking.Data
```

**Name with it:** One of the hooks below for SQL replay in the app.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
