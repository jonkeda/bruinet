# Bruinet.Stride

Stride game UI testing on the call model (AD-010): the client for Bruinet.Stride.Automation, with generated controls, pages, containers and collections, one call per member over the automation pipe.

```bash
dotnet add package Bruinet.Stride
```

**Name with it:** Bruinet.Stride.Automation in the game.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
