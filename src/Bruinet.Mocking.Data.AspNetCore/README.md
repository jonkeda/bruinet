# Bruinet.Mocking.Data.AspNetCore

The SQL replay test-id hook for an ASP.NET Core app in a process of its own: each request recorded or replayed in its test's session.

```bash
dotnet add package Bruinet.Mocking.Data.AspNetCore
```

**Name with it:** Bruinet.Mocking.Data, in an ASP.NET Core app.

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
