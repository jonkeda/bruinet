# Bruinet.Logging

An app's log during a Bruinet test, kept by the step that made it: an ILoggerProvider to add to the app's services.

```bash
dotnet add package Bruinet.Logging
```

**Name with it:** The app under test, which adds AddBruinetStepLog().

The packages come from the organisation's GitHub Packages feed; Bruinet's README says which package goes with which
app, and what each targets.
